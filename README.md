# WhisperMac

WhisperMac записывает речь, пока вы держите **правый ⌘ Command**, распознаёт её локально и вставляет текст в активное поле ввода после отпускания клавиши. Приложение продолжает работать, когда его окно свёрнуто или закрыто.

## Установка на новом Mac

Понадобятся интернет и несколько гигабайт свободного места: одна только модель занимает около **1,5 ГБ**. Homebrew и заранее установленный CMake не нужны. Установщик собирает программу под процессор данного Mac.

1. Откройте [репозиторий WhisperMac](https://github.com/TheAkseon/WhisperMac), нажмите **Code → Download ZIP** и распакуйте архив. Если Git уже установлен, можно вместо этого клонировать репозиторий.
2. Откройте приложение **Терминал** через Spotlight (`⌘ Пробел` → «Терминал»).
3. Наберите `cd ` с пробелом, перетащите **распакованную папку WhisperMac** из Finder в окно Терминала и нажмите Return. Терминал перейдёт в нужную папку.
4. Выполните:

   ```bash
   bash install.sh
   ```

5. Если macOS предложит установить **Xcode Command Line Tools**, подтвердите установку и дождитесь её завершения. После этого **повторите `bash install.sh`** в той же папке. При первом запуске скрипт скачает CMake при необходимости, исходники `whisper.cpp` и модель на 1,5 ГБ. Это может занять время в зависимости от интернета и Mac.
6. Дождитесь сообщения **`WhisperMac — INSTALLED`**. Установщик покажет путь к приложению в строке `App:`. Обычно это `/Applications/WhisperMac.app`; если запись в `/Applications` недоступна, используется `~/Applications/WhisperMac.app`.

Установщик скачивает модель **до запуска приложения** в `~/.whispermac/models/ggml-medium.bin`, проверяет её контрольную сумму, собирает `whisper-cli`, сохраняет движок в `~/.whispermac/bin` и резервную копию внутри приложения, затем настраивает запуск при входе в macOS. На Mac с Apple Silicon движок собирается с Metal; если GPU-обработка не запустится, приложение повторит попытку на CPU.

### Разрешения при первом запуске

Откройте WhisperMac, если его окно не появилось само. В окне приложения есть статусы **Shortcut**, **Paste** и **Mic**. Нужны три разрешения в **Системные настройки → Конфиденциальность и безопасность**:

1. **Микрофон / Microphone.** Когда macOS покажет запрос, нажмите «Разрешить». Если ранее отказали, включите WhisperMac в разделе «Микрофон».
2. **Мониторинг ввода / Input Monitoring.** Нажмите в WhisperMac кнопку **Input Monitoring**: она откроет нужный раздел настроек. Включите переключатель напротив WhisperMac. Это нужно, чтобы правый ⌘ работал в других приложениях и при свёрнутом окне.
3. **Универсальный доступ / Accessibility.** Нажмите кнопку **Accessibility**, затем включите WhisperMac в открывшемся разделе. Это разрешение нужно для глобального обработчика клавиши AppKit и автоматической вставки текста в поле с курсором.

**Кнопки только открывают настройки; разрешения выдаёт сам владелец Mac.** macOS может попросить Touch ID или пароль. Если WhisperMac отсутствует в списке, нажмите `+` и выберите приложение по пути из строки `App:` установщика. После выдачи разрешений нажмите **Retry**. Если статус не обновился, нажмите правой кнопкой на значок WhisperMac в Dock, выберите **Завершить** и откройте приложение снова: простое закрытие окна не завершает процесс. Проверьте в окне: `Shortcut: connected`, `Paste: allowed`, `Mic: allowed`, а под выбором модели — `Model ready`.

### Проверка

1. Откройте **TextEdit** и поставьте курсор в пустой документ.
2. Удерживайте **правый ⌘**, произнесите фразу и отпустите клавишу. Запись должна идти всё время, пока клавиша нажата.
3. Дождитесь окончания распознавания. Текст должен появиться там, где стоял курсор, **без ручного ⌘V**. Он также сохраняется в буфере обмена.
4. Сверните окно WhisperMac и повторите проверку: фоновая запись должна продолжать работать.

Чтобы WhisperMac запускался после входа в систему, проверьте **Системные настройки → Основные → Объекты входа и расширения**. Установщик создаёт агент автозапуска; WhisperMac должен быть разрешён в объектах входа или фоновой активности.

## Нагрузка на Mac

По умолчанию используется многоязычная модель **Medium** (файл около 1,5 ГБ). На Apple Silicon сборка использует **Metal**, на Intel Mac — CPU. После каждого отпускания правого ⌘ приложение запускает отдельный процесс распознавания; тот загружает модель, обрабатывает запись и завершается. Поэтому во время обработки возможны пики памяти, но модель не остаётся постоянно загруженной внутри WhisperMac. Файл модели остаётся **на диске** в `~/.whispermac/models`. На Apple Silicon GPU и CPU используют общую оперативную память: Metal снижает нагрузку на CPU, но не переносит модель в отдельную видеопамять.

Текущие исходники ограничивают распознавание **двумя CPU-потоками**, чтобы оставить ресурсы другим приложениям. Это ограничение начинает действовать только после сборки и установки новой версии через `bash install.sh`; уже установленная ранее версия сама не обновится. Первый запуск Metal может быть медленнее из-за подготовки GPU, последующие обычно быстрее.

Если во время обработки Mac замедляется, в окне WhisperMac можно выбрать **Small (multilingual)** или **Base (multilingual)** и нажать **Download**. Эти модели занимают меньше памяти и обычно обрабатывают речь быстрее, но точность может быть ниже, чем у Medium. После загрузки выбранной модели следующая запись будет использовать её. Обновление самого приложения для смены модели не требуется.

### Исправление задержек ввода в версии 1.2

Версия 1.2 убирает дополнительный `CGEventTap` и таймер, который мог пересоздавать его каждые пять секунд без явной инвалидизации системного порта. Используется одна пара обработчиков AppKit: глобальный для других приложений и локальный для окна WhisperMac. Повторное подключение сначала удаляет прежние регистрации; запуск записи выполняется после возврата из обработчика клавиши. Выход из приложения удаляет регистрации и останавливает запись.

Для этого исправления нужно **полное обновление** через `bash install.sh`: режим `--engine-only` обновляет только распознавание и не исправляет обработчики в старом приложении. Модель Medium, Metal и способ автоматической вставки сохраняются. После обновления проверьте разрешения, фоновую диктовку и несколько последовательных записей. Строки `keyboard resources` в `~/.whispermac/debug.log` показывают число системных обработчиков, принадлежащих приложению; при обычных повторных диктовках оно не должно нарастать. Низкая загрузка CPU и нулевой swap сами по себе не исключают задержки доставки событий ввода.

Утечка старого способа освобождения воспроизведена на macOS 26.6.2: после 20 циклов удаления источника из run loop и сброса ссылок оставалось 20 Mach-портов; при явной инвалидизации после обработки run loop оставалось 0. Воспроизведение: `bash Tests/reproduce-port-leak.sh`. Оно создаёт только собственные порты тестового процесса, не подключается к клавиатуре и не запускает модель. Этот тест подтверждает дефект освобождения; отсутствие лагов нужно дополнительно подтвердить на установленной версии 1.2 при последовательных диктовках.

Для проверки жизненного цикла обработчиков без микрофона и модели разработчик может выполнить `bash Tests/run.sh`. Тест проверяет повторные подключения, порядок событий, очистку регистраций и защиту от событий старого обработчика; реальные разрешения и вставку нужно проверять в установленном приложении.

## Если что-то не работает

- **Нет записи по правому ⌘:** проверьте `Shortcut: connected`, разрешение «Мониторинг ввода» и флажок **Enable (Right ⌘ to record)** в окне WhisperMac. Нажмите **Retry** или перезапустите приложение.
- **Запись есть, текста нет:** проверьте `Mic: allowed` и `Model ready`. Если модель отсутствует, нажмите **Download** в окне приложения. Если скачивание прервалось, проверьте интернет и свободное место.
- **Текст попадает в буфер, но не вставляется:** сначала проверьте, что курсор стоит в поле **другого** приложения: когда активно окно самого WhisperMac, вставлять текст некуда. Затем проверьте `Paste: allowed` и разрешение «Универсальный доступ». После обновления приложения macOS иногда сохраняет старую запись разрешения: в обычном Терминале выполните `killall WhisperMac; tccutil reset Accessibility com.whispermac`, удалите старые записи WhisperMac из списка «Универсальный доступ», добавьте через `+` именно `/Applications/WhisperMac.app` (или путь `App:` из установщика), включите переключатель и откройте приложение снова.
- **Установщик сообщил `launchctl bootstrap ... error 5`:** приложение уже установлено. Откройте `/Applications/WhisperMac.app` через Finder; если его там нет, проверьте `~/Applications/WhisperMac.app`. Затем проверьте раздел «Объекты входа и расширения». Запуск установщика через некоторые среды автоматизации может мешать `launchctl`; `sudo launchctl` для обычной установки не требуется.
- **Нужны подробности ошибки:** смотрите `~/.whispermac/build.log`, `~/.whispermac/stderr.log` и `~/.whispermac/debug.log`. Журнал приложения записывает этапы работы, но не сохраняет распознанный текст.

Для **полного обновления приложения** скачайте свежий репозиторий и снова выполните `bash install.sh`. Модель повторно не скачивается, если её контрольная сумма верна. Приложение подписывается локально, поэтому после полного обновления macOS может потребовать заново включить разрешения. Установщик оставляет предыдущую сборку рядом с новой и печатает путь `Backup:` для отката.

После первого перехода на версию **1.1 или новее** можно обновлять только движок командой `bash install.sh --engine-only`. Она не заменяет само приложение и не меняет его разрешения. На старой версии этот режим недоступен: сначала требуется одно полное обновление.

## Почему нельзя просто установить DMG

**DMG не входит в скачанный репозиторий** и не является готовым установщиком для другого Mac. Команда `bash install.sh --app-only-dmg` создаёт отдельный DMG только с приложением и `whisper-cli`, **без модели**. Если перенести один такой DMG, модель придётся скачивать кнопкой **Download** внутри приложения, а автозапуск настраивать отдельно. Для первого использования на новом Mac применяйте шаги установки выше.
